# Meta-Chunks

Meta-chunks are a special chunk type (`meta`) that capture cross-cutting patterns about a person's *other* patterns. They're the portrait reflecting on itself.

## What Makes Them Special

Regular chunks capture individual facts, beliefs, and behaviors. Meta-chunks capture the *structure* of someone's thinking:

- "Tends to frame every problem as a coordination problem" (pattern about patterns)
- "When stressed, falls back on first-principles reasoning rather than heuristics" (meta-pattern about behavior)
- "Has a blind spot: consistently underestimates emotional factors in technical decisions" (self-aware limitation)

## Why They Matter

Meta-chunks give a clone **self-awareness**. Without them, a clone can reproduce individual positions but can't explain its own tendencies. With them, it can say things like:

> "I notice I keep framing this as an org design question — that's a pattern of mine. Let me try to look at it purely from a technical angle instead."

This level of self-reflection is impossible with flat personality profiles.

## Generation

Meta-chunks are typically generated by the Extractor's `generateMetaChunks()` method, which:

1. Analyzes the full portrait for recurring patterns
2. Identifies clusters with high internal density
3. Detects cross-cluster patterns (e.g., the same reasoning style appearing in both technical and leadership contexts)
4. Generates meta-chunks with appropriate confidence scores

```bash
# Generate meta-chunks via CLI
athanor meta-generate \
  --portrait ./portrait.json \
  --provider anthropic \
  --api-key $ANTHROPIC_API_KEY
```

## Examples

```json
{
  "chunk_id": "MP-META-001",
  "cluster": "meta-patterns",
  "type": "meta",
  "uniqueness": "HIGH",
  "confidence": 0.78,
  "content": "Applies 'make the wrong thing hard, not the right thing easy' as a universal design principle — shows up in API design, team process, hiring filters, and even personal habits."
}
```

```json
{
  "chunk_id": "MP-META-003",
  "cluster": "meta-patterns",
  "type": "meta",
  "uniqueness": "CRITICAL",
  "confidence": 0.85,
  "content": "Strong tendency to resolve apparent contradictions by finding the level of abstraction where both positions are simultaneously true. Rarely accepts binary trade-offs at face value."
}
```

## Placement in the Graph

Meta-chunks typically sit in the `meta-patterns` cluster and link to chunks across multiple other clusters via INSTANTIATES or EXPRESSED_THROUGH relations. They act as high-level anchors in the graph — connected to many nodes but belonging to none of the domain-specific clusters.
